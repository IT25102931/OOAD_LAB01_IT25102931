# SE2012 - Practical 01 - Java Basics

Repository for SE2012 (OOAD) Practical 01.

## Programs
- Welcome.java - Question 1: reads the first and last name and prints a welcome message.
- Marks.java - Questions 2 and 3: menu driven program to manage the marks of n students
  for Mathematics, Chemistry and Physics, with a grade summary table.

## How to run
javac Welcome.java   then   java Welcome
javac Marks.java     then   java Marks

## Marks.java commands
add [studentID], update [studentID] [subjectID], average_s [subjectID],
average [studentID], total [studentID], grades, menu, exit
